## ✨ Features

- **Original Bespoke Emblem**: Metallic chrome vector mark with specular highlights.
- **Interactive 3D-Feel Car Configurator**:
  - Multi-angle views (Front 3/4 Perspective, Side Streamline Profile, Cockpit Interior).
  - Real-time paint swapping (Obsidian Black, Celestial Silver, Glacier White, Deep Blue, Crimson Ruby).
  - Wheel options (18" Aero Turbine, 19" Sport V-Spoke, 20" Diamond Cut).
  - Interior leather trims & ADAS packages.
  - Live dynamic price calculation & monthly EMI calculator.
- **Interactive Headlights & Studio Lighting**: Toggle matrix LED lights on/off with real-time beam flare effects.
- **Technology Showcase**: Interactive deep dives for *HENRY SmartDrive (L2+ ADAS)*, *HENRY Connect*, *HENRY SmartSense*, and *HENRY PowerCore*.
- **Safety Architecture ("Safety Comes Standard")**: 8 standard airbags, 360° collision shield, and Boron steel monocoque callouts.
- **Book a Test Drive**: Multi-step booking engine with instant Booking Pass & reference ID generation.
- **Verified Customer Reviews**: Demo testimonial cards with star ratings.
- **Responsive Luxury Design**: Dark obsidian theme, glassmorphism, smooth animations, and mobile drawer menu.

## 🚀 Getting Started

### Local Development

1. Clone this repository:
   ```bash
   git clone https://github.com/Harrish0007/henry-cars.git
   cd henry-cars
   ```

2. Start a local server:
   ```bash
   # Using Python
   python -m http.server 8000

   # Or using Node.js / npx
   npx serve
   ```

3. Open [http://localhost:8000](http://localhost:8000) in your browser.
